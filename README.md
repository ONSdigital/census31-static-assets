# Census static assets

This repo is just used to hold the static assets for the Census. This will be a repo managed by the eQ team but will include files used by both the eQ and RH systems.
This will include CSS file overrides that will override some of the styles from the Design System and also some SVG image files that will be used for the Census.
These files will be pushed up to the CDN for them to be downloaded by users browsers as they use the eQ and RH.
